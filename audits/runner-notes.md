For every audit:
- create tickets for meaningful findings
- avoid duplicate tickets already in /bugs or CR/DR
- prioritize by user impact and business value
- distinguish completed fixes from follow-up work
- prefer concrete reproduction and verification steps

Recommended sprint audit order:
1. Regression / workflow
2. Performance / responsiveness
3. UX clarity / visual polish
4. Retention / behavior / product coherence
5. Code quality / maintainability
