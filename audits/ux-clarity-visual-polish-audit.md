# UX Clarity and Visual Polish Audit

## Cadence

- Every sprint for changed user-visible surfaces

## Trigger conditions

- Layout, copy, interaction states, hierarchy, affordances, mobile behavior, accessibility-adjacent clarity issues

## Required inputs

- Production screenshots or real UI review
- Changed routes and user flows
- Existing same-run findings and tickets

## Release-gating

- Only when the issue causes workflow failure, severe ambiguity, or accessibility risk

## Deliverable

Every finding must include:

- Finding type
- Evidence from the actual interface
- Confidence
- Affected routes, breakpoints, and states
- Why now
- Root cause
- Duplicate or related work check
- Ticket recommendation with owner hint
